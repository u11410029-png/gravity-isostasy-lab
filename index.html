1. 大地均衡的假說及模型 (Isostasy)

基礎核心理論

💡 什麼是大地均衡 (Isostasy)？

大地均衡假說認為，地球表層較輕且具浮力的地殼（或岩石圈）漂浮在具有黏滯性、表現如同流體的較高密度地函（軟流圈）之上，猶如冰山漂浮於海面一般。

在地質時間尺度下，地表地形起伏（如高山或深海）所造成的質量負荷增減，會由深部的質量分佈進行浮力補償，使系統趨向靜力平衡 (Hydrostatic Equilibrium)。

補償深度 (Compensation Depth) 準則：

在某一特定補償深度 C−C′C-C'C−C′ 及其以下，各個垂直岩柱上方所施加的總靜水壓力完全相等：

P=∫0Dρ(z)gdz=常數P = \int_0^D \rho(z) g dz = \text{常數}P=∫0D​ρ(z)gdz=常數
Airy Model (艾利模型)

「同密度、不同厚度」

核心假設：地殼具有均勻固定密度 (ρc\rho_cρc​)，地函密度為 ρm\rho_mρm​ (ρm>ρc\rho_m > \rho_cρm​>ρc​)，但地殼厚度隨地表高程變化。

▲ 艾利模型：高山下方有低密度的深「山根 (root)」，海洋下方有較薄地殼與地函隆起的「反根 (anti-root)」
● 補償機制：高山地區下方會向下延伸較深的低密度「山根 (rrr)」（如 h1h_1h1​ 對應較深山根 r1r_1r1​，h2h_2h2​ 對應較淺山根 r2r_2r2​）。當山根產生的質量虧損 (mass deficiency) 剛好抵銷地表多餘的地形負荷 (excess load) 時，各岩柱在補償面 C−C′C-C'C−C′ 處壓力相等。
● 山根厚度公式：
r=ρcρm−ρc⋅hr = \frac{\rho_c}{\rho_m - \rho_c} \cdot hr=ρm​−ρc​ρc​​⋅h
若取 ρc=2.67 g/cm3,ρm=3.27 g/cm3\rho_c = 2.67\text{ g/cm}^3, \rho_m = 3.27\text{ g/cm}^3ρc​=2.67 g/cm3,ρm​=3.27 g/cm3，山根深度約為地表山高的 4.45 倍！
Pratt Model (普拉特模型)

「同深度、不同密度」

核心假設：在一個固定不變的補償深度 DDD（補償面 C−C′C-C'C−C′ 平齊）以上，各垂直岩柱底部深度相同，但岩石柱的側向密度不同。

▲ 普拉特模型：在補償基準面 DDD 處切齊，山脈海拔越高密度越小 (ρ1<ρ2<ρc\rho_1 < \rho_2 < \rho_cρ1​<ρ2​<ρc​)
● 補償機制：海拔越高的山脈由密度越小的岩層組成（如 ρ1<ρ2<ρc\rho_1 < \rho_2 < \rho_cρ1​<ρ2​<ρc​），海盆下方則由密度較大的岩層組成，藉此在固定深度 DDD 處達成相同壓力。
● 山脈密度公式：
ρ1=ρc(DD+h1)\rho_1 = \rho_c \left( \frac{D}{D + h_1} \right)ρ1​=ρc​(D+h1​D​)
適用於中洋脊兩側熱膨脹、洋底地熱構造與岩石圈橫向熱結構變化區。

依實際補償程度區分的三種狀態（以均衡重力異常判定）

以均衡重力異常判定： ΔgI=ΔgB−ΔgR\Delta g_I = \Delta g_B - \Delta g_RΔgI​=ΔgB​−ΔgR​ 其中 ΔgB\Delta g_BΔgB​ 為觀測到的布蓋重力異常，ΔgR\Delta g_RΔgR​ 為理論補償模型計算出的深部根部重力異常。

① 完全補償 (Complete compensation)
ΔgB=ΔgR  ⟹  ΔgI≈0\Delta g_B = \Delta g_R \implies \Delta g_I \approx 0ΔgB​=ΔgR​⟹ΔgI​≈0

實際山根與理論計算山根一致。地表載重被深部完全補償，地殼處於穩定靜力平衡狀態。

2. 台灣是否達大地均衡？其證據為何？

實務觀測資料論證
❌ 未達大地均衡

核心結論：台灣整體而言「並未達到靜力大地均衡」！

台灣目前處於非均衡的動態造山調整狀態（補償不足 Undercompensated）。從講義所附的台灣構造與重力異常資料，可歸納出以下 3 大關鍵證據：

01

中央山脈出現顯著的自由空間正異常 (Free-Air Anomaly)

Yen et al. (1990) 台灣自由空間異常圖

+100 ~ +300 mgal 強烈正異常帶

根據均衡原理，若廣大海拔地區已達局部均衡補償，深部低密度山根應抵銷地表地形的重力效應，使自由空間異常趨近於零；高地形區呈現強烈正異常，直接顯示台灣山脈尚未達到局部均衡補償。

02

布蓋重力異常呈強烈東西不對稱與劇烈梯度

Yeh & Yen (1992); Masson et al. (2012)

-50 → +200 mgal 短距離劇變

中西部至中央山脈西側為負異常區（最低約 -50 至 -100 mgal，反映地殼增厚與山根效應），但往東跨過花東縱谷至海岸山脈與外海時，布蓋異常在極短距離內急遽轉為 +50 至 +200 mgal 以上的高正異常，並非對稱於地形的靜力平衡分佈。

03

Masson et al. (2012) 構造與密度剖面

8.2 cm/yr 歐亞 ⇄ 菲律賓海板塊

台灣位於快速聚合碰撞帶。重力與密度剖面顯示，地殼增厚與莫氏面 (Moho) 下凹（最深超過 40~50 km）受到強烈水平構造擠壓、板塊隱沒碰撞及地表快速隆升侵蝕主導，使得地形抬升與深部根部調整來不及鬆弛至靜力均衡。

7. 如何將本互動網頁部署到 GitHub Pages？

快速上線教學

本專案採用純靜態架構（HTML5 + CSS3 + 純原生 JavaScript），無須任何後端伺服器或打包工具，一鍵推送到 GitHub 即可永久免費上線！

步驟 1

在 GitHub 上建立新儲存庫 (Repository)

  1. 登入 GitHub.com。
  2. 點擊右上角「+」按鈕，選擇「New repository」。
  3. 設定 Repository name（例如：gravity-isostasy-lab）。
  4. 將權限保持為 Public（公開）。
  5. 不要勾選 Initialize with README（我們資料夾內已備妥完整的 README.md）。
  6. 點擊「Create repository」。
步驟 2

在本地資料夾執行 Git 上傳指令

打開終端機（Terminal / PowerShell），切換至本專案目錄並依序執行以下指令：

bash / powershell 
# 1. 進入本專案資料夾
cd gravity-geophysics-web

# 2. 初始化 Git 本地倉庫
git init

# 3. 將所有檔案加入暫存區
git add .

# 4. 提交版本記錄
git commit -m "feat: 發布米色手寫風重力探勘與大地均衡互動筆記"

# 5. 將預設分支命名為 main
git branch -M main

# 6. 綁定你的遠端 GitHub Repository（請將 YOUR-USERNAME 與 REPO-NAME 替換成你的）
git remote add origin https://github.com/YOUR-USERNAME/gravity-isostasy-lab.git

# 7. 推送至遠端 GitHub 儲存庫
git push -u origin main
步驟 3

啟用 GitHub Pages 免費靜態託管

  1. 進入你的 GitHub 儲存庫頁面，點選上方的「Settings（設定）」。
  2. 在左側側邊欄中找到「Pages」（在 Code and automation 分類下）。
  3. 在「Build and deployment」下方：
    • Source 選擇「Deploy from a branch」。
    • Branch 選擇 main 分支，資料夾選擇 / (root)。
  4. 點擊「Save（儲存）」。
  5. 等待約 1~2 分鐘重新整理頁面，最上方會出現綠色勾勾與你的專屬網址：
    https://YOUR-USERNAME.github.io/gravity-isostasy-lab/
